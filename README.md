# Manohari M - Software Developer Portfolio

Static portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` - portfolio structure/content
- `style.css` - styling and responsive template
- `script.js` - typing effect, decorative graph and scroll reveal
- `profile.jpg` - profile image
- certificate/document PDFs - downloadable from the portfolio

## Important

Keep `profile.jpg` in the same folder as `index.html`.

The certificate and internship document buttons use the HTML `download` attribute, so visitors can download the PDF files directly from the portfolio.
