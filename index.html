01

Cloud-Based AI Smart Printing System

Ongoing

A cloud-based smart printing platform designed to make document printing more secure, automated and convenient. The system provides a complete workflow starting from document upload and preview to page-count calculation, pricing, payment verification, printer selection and print-job tracking. It is designed to connect users with available printers while reducing manual intervention and improving the overall printing workflow.

The system uses a QR-code-based web portal through which users can access the printing interface and submit documents. A FastAPI backend manages requests, authentication, document processing and print-job operations, while PostgreSQL stores users, print jobs, pricing information, printer details and transaction-related records. UUID-based job identification provides reliable tracking for individual printing requests.

Security is incorporated into the document-handling process using JWT-based authentication and AES-256-GCM encryption. Temporary document files are handled securely and can be removed after successful printing to reduce unnecessary data retention. A Python-based local print agent communicates with the cloud backend through WebSockets to receive authorized print jobs and forward them to connected printers.

The printing workflow also includes queue management and intelligent printer selection. FCFS-based queue handling helps organize incoming requests, while printer availability and workload can be considered when selecting an appropriate printer. An owner/operator dashboard provides visibility into print jobs, printer activity and operational information.

  • QR-code-based web portal and FastAPI backend
  • JWT authentication and UUID-based print-job tracking
  • AES-256-GCM document encryption and secure file handling
  • WebSocket-connected Python local print agent
  • FCFS queue management and intelligent printer selection
  • PostgreSQL database and management dashboard
  • Automated page counting, pricing and payment verification

02

Heart Disease Prediction System

Completed

A Python and Streamlit-based machine-learning application designed to estimate heart-disease risk from clinical information. The project uses the Framingham heart-study dataset and provides an interactive interface where users can enter relevant clinical attributes and obtain a model-based prediction.

The dataset contains 4,240 records and 15 clinical attributes. Data preprocessing and feature preparation were performed before training the machine-learning models. StandardScaler was used to normalize numerical features and maintain a consistent preprocessing pipeline between model training and prediction.

Multiple classification algorithms were explored, including Logistic Regression, Support Vector Machine and Random Forest. Comparing different models helped evaluate their suitability for the prediction task. The final application integrates the trained machine-learning workflow with a Streamlit interface, allowing predictions to be generated through an accessible dashboard.

The application also provides prediction results and downloadable PDF reports, making the project more useful as an interactive demonstration of data preprocessing, machine learning, model inference and application deployment.

  • 4,240 Framingham records and 15 clinical attributes
  • Data preprocessing and feature preparation
  • Logistic Regression, SVM and Random Forest models
  • StandardScaler-based preprocessing pipeline
  • Interactive Streamlit prediction dashboard
  • Downloadable PDF prediction reports
